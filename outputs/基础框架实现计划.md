# 内容生成平台基础框架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个无需真实模型密钥即可本地运行的纵向闭环，完成文章创建、模拟知识梳理与大纲、结构化内容块编辑、公众号预览和富文本复制。

**Architecture:** 使用 Next.js App Router 构建模块化单体，服务端通过仓储和端口接口隔离数据库、生成模型与任务调度。基础阶段使用 Node 内置 SQLite 和确定性的演示生成适配器，但所有业务调用都只依赖接口，后续可以替换为 PostgreSQL、真实模型和异步队列。

**Tech Stack:** Node.js 26、pnpm、Next.js 16、React 19、TypeScript 5、Zod、Node `node:sqlite`、Vitest、Testing Library、Playwright、Lucide React、原生 CSS。

**Spec:** `outputs/微信公众号图文内容生成平台-产品需求设计.md`

## Global Constraints

- 第一阶段只服务单个个人创作者，不实现团队、计费、多租户或公众号接口直发。
- 文章必须保存为有序的结构化内容块，不能把整篇文章仅保存为 HTML。
- AI 或模拟生成任务只能写入明确目标，不得覆盖用户已编辑的非目标内容块。
- 预览和复制必须使用同一个公众号 HTML 渲染器。
- 桌面端提供完整工作台；移动端只保证查看和预览。
- 外部生成服务必须位于端口接口之后，Web 组件不得直接调用模型供应商。
- 所有用户可见界面使用中文；代码标识符、路径和提交信息使用英文。
- 基础阶段不需要模型密钥，`DemoContentGenerator` 必须输出确定性结果以支持测试。
- 每个任务执行测试驱动开发：先写失败测试，确认失败，再写最小实现并确认通过。

## 2. Stable Interfaces

```ts
export type ArticleStatus =
  | "draft"
  | "brief_ready"
  | "outline_ready"
  | "editing"
  | "ready_to_publish";

export type BlockType =
  | "heading"
  | "paragraph"
  | "quote"
  | "callout"
  | "knowledge_card"
  | "image";

export interface ContentBlock {
  id: string;
  type: BlockType;
  content: string;
  order: number;
  level?: 1 | 2 | 3;
  altText?: string;
  version: number;
}

export interface OutlineSection {
  id: string;
  title: string;
  order: number;
}

export interface KnowledgeBrief {
  oneSentence: string;
  concepts: string[];
  prerequisites: string[];
  misconceptions: string[];
  analogies: string[];
  unsupportedNotes: string[];
}

export interface Article {
  id: string;
  title: string;
  topic: string;
  status: ArticleStatus;
  brief: KnowledgeBrief | null;
  outline: OutlineSection[];
  blocks: ContentBlock[];
  createdAt: string;
  updatedAt: string;
}

export interface ArticleRepository {
  list(): Promise<Article[]>;
  findById(id: string): Promise<Article | null>;
  create(input: { topic: string; title?: string }): Promise<Article>;
  save(article: Article, expectedUpdatedAt: string): Promise<SaveArticleResult>;
}

export type SaveArticleResult =
  | { kind: "saved"; article: Article }
  | { kind: "conflict" };

export interface GeneratedFoundation {
  title: string;
  brief: KnowledgeBrief;
  outline: OutlineSection[];
  blocks: ContentBlock[];
}

export interface ContentGenerator {
  generateFoundation(input: { topic: string }): Promise<GeneratedFoundation>;
}
```

`SqliteArticleRepository` constructor and methods must exactly implement:

```ts
export class SqliteArticleRepository implements ArticleRepository {
  constructor(private readonly db: DatabaseSync) {}
  list(): Promise<Article[]>;
  findById(id: string): Promise<Article | null>;
  create(input: { topic: string; title?: string }): Promise<Article>;
  save(article: Article, expectedUpdatedAt: string): Promise<SaveArticleResult>;
}
```

`save` performs one SQL `UPDATE ... WHERE id = ? AND updated_at = ?`. It returns `{ kind: "conflict" }` when the affected row count is zero and otherwise returns the parsed article with a new `updatedAt` value.

- [ ] **Step 3: Implement deterministic generation**

For any topic, the adapter returns:
